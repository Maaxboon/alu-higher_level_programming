#Objects:
In JavaScript, objects are collections of key-value pairs. They can store various types of data and functions (methods).

#Scopes: 
Scope determines the accessibility of variables. JavaScript has function scope and block scope. Variables defined inside a function are not accessible outside of it.

#Closures: 
A closure is a function that retains access to its lexical scope, even when the function is executed outside that scope. This allows the function to remember the environment in which it was created.
